# tgbot
Модуль, который реализует минимальный фукнционал telegram-бота.

Умеет получать ID пользователя, которому надо слать сообщения и потом шлет ему эти сообщения. 

Настройки в файле settings.json

## Пример использования
Заполняем в файле `settings.json`  токен бота в ключе `tgtoken`. Поле `tguser` заполнять не надо, оно заполнится при регистрации.

Затем проводим регистрацию (получаем id пользователя), а затем посылаем сообщения.

```python
import bot

bot.register() # Запустить бота и пройти начальную регистрацию

sendMsg("Hello from bot") # Послать сообщение
```
Есть возможность посылать сообщение через командную строку

```
python3 bot.py "hello some message"
```
## Installation

```shell
sudo apt-get install python3 python3-pip
pip3 install telebot
```
